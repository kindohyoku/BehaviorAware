Abstract

Well-designed indoor scenes should prioritize how people can act within a space rather than merely what objects to place. However, existing 3D scene generation methods emphasize visual and semantic plausibility, while insufficiently addressing whether people can comfortably walk, sit, or manipulate objects.

We present a Behavior-Aware Anthropometric Scene Generation framework that leverages vision–language models to analyze object–behavior relationships and translates spatial requirements into parametric layout constraints adapted to user-specific anthropometric data. Through individual and group user studies with motion-captured trajectories, we show that layouts generated with our framework yield shorter task-completion times, fewer detours, cleaner action sequences, and a substantially larger usable manipulation volume than path-only and baseline layouts.

Overview

Four ideas drive the framework. They map onto the method but are not the method itself — the method has seven stages organized into two phases (see below).

1

Behavior-First Scene Design

Plan how people will act in a room before deciding where objects go. Function precedes geometry, so layouts are evaluated by what users can do in them — not by what they look like.

2

Anthropometric Parameterization

Every spatial constraint scales with the user's body — shoulder width H4, arm reach H3, sitting height V1. The same scene is re-solved per individual.

3

VLM + LLM Reasoning Engine

A VLM reads object affordances from multi-view renders; an LLM clusters them into functional zones and writes the constraint program. The pipeline is language-model native end-to-end.

4

Motion-Capture Validation

Real participants perform tasks in an 8-camera mocap studio. We measure time, detours, action chains, and the volume their bodies actually fill — not just survey scores.

Phase II · Constraint-based Layout Generation

Two stages (F–G) that compile the behavior tags + anthropometry into a solvable program and produce the final scene.

F

Anthropometric-based Constraint LLM

The LLM emits position, orientation and height constraints. Each term is parameterized by user body measurements captured from an A-pose.

H3 arm reach H4 shoulder width H6 hand depth V1 sitting / standing height 
solver = ConstraintSolver()
width_d  = desk.width * 2                 # Desk + Desk
depth_d  = desk.depth + chair.depth       # Desk + Chair

for i in range(N):
    # Orientation — against wall, for space efficiency
    solver.against_wall(desks[i], walls[0])

    # Position — min/max spacing scaled by accessibility gap
    if i < N - 1:
        solver.distance_constraint(desks[i], desks[i+1],
            min = 0.1 + (width_d / 2),
            max = 0.3 + (width_d / 2) + Tolerance)

    # Chair must face the desk
    solver.point_towards(chairs[i], desks[i])

    # Drawer at arm-reach H3 from chair
    solver.distance_constraint(drawers[i], chairs[i],
        max = H3 - Tolerance)
G

Sequential Group Optimization VLM

Groups are solved one after another so later groups inherit the geometry of earlier ones. The solver runs in Blender and outputs a Behavior-Aware Anthropometric Scene tailored to the participant.

Key concept

Human–Object Manipulation Space

A per-action 3D bounding volume sized by the user's anthropometry that must stay collision-free for the action to be physically achievable. Reserving this volume — not just a 2D walkable path — is what separates Human-Operational layouts from prior Path-Only approaches.

Experiments

We compare three layout conditions across two scene categories (Office, Lounge) under both individual (60 min) and group (120 min) tasks in an 8-camera motion-capture room.

Baseline Existing scene-generation method — no behavior reasoning.
PO · Path-Only Reserves a navigable path between objects.
HO · Human-Operational (Ours) Reserves the full anthropometric manipulation volume for every action.

Results

Task Completion Time sec, lower is better

How quickly participants finished the assigned task.

Trajectory Count #, lower is better

Distinct path branches per participant — fewer detours, clearer wayfinding.

Sequence Action Labeling #, lower is better

Action-state transitions during the task — lower means a cleaner action chain.

Volumetric Occupancy Ratio 0–1, higher is better

Fraction of the reserved manipulation volume actually filled by the participant's body.

Across both Office and Lounge scenes, HO significantly reduced completion time, trajectory count and sequence noise while raising volumetric occupancy — meaning the reserved space is actually used.
